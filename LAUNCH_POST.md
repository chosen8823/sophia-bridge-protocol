# Launch post

Today we are releasing TPSI-1: a tiny, falsifiable benchmark for a large
question.

When information moves between representations, what survives—the payload, or
the relationships that make the state what it is?

TPSI-1 creates a relational state, changes its coordinates/order/scale/encoding,
and asks an invariant description to recognize it. Then it deliberately breaks
the relationships and asks the same measure to reject it. The baseline, controls,
thresholds, tests, and failures are all visible.

The first implementation is intentionally small and runs without dependencies.
There is also a batched PyTorch path for accelerator sweeps.

This release is not a consciousness claim and not a proof about natural
language. It is the measuring instrument we can now try to break.

Core rule: **encode the transformation rules, not the payload.**

Run it. Change the controls. Find the failure. Bring receipts.
