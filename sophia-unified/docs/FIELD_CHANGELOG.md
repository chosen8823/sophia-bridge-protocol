# Field Changelog

Only explicitly material shifts enter this surface.  Ordinary ingestion,
imports, test output, tokenisation, and background events remain lower evidence
unless marked material.

## 2026-09-08 — Inward / Outward boundary admitted

What changed:

- The filesystem ingestion membrane now treats inward canonical event creation
  as the primary boundary.
- Archive movement is an outward expression and is opt-in by default.
- The recursive analysis prompt was added as a portable recovery/reconstruction
  artifact for conversation exports.

What it means:

- The kernel stabilises before the fabric amplifies.
- Adapters can carry, render, archive, sync, or delegate state, but they do not
  own durable truth.
- The field can grow without letting motion masquerade as evolution.

What it opens next:

- A GitHub-ready Sophia kernel/fabric export with local secrets and mutable
  state excluded.
- A second-stage implementation prompt generated from the five-pass recursive
  analysis result.
- A safe bridge from filesystem carriers into semantic atoms, OPTE receipts,
  and later outward projection membranes.

## 2026-09-08 — GitHub branch engines admitted

What changed:

- GitHub branches can now be treated as temporary engine chambers.
- Each branch event can run a Sophia verification slice and emit a deterministic
  branch transform atom.
- The runner VM is execution tissue only; the uploaded atom artifact is the
  durable receipt.

What it means:

- The GitHub ecosystem can animate around a central transform atom without
  making every branch an always-on server.
- Branch state becomes observable as canonical OPTE-shaped evidence.
- Central aggregation can be added later without changing branch-local tests.

What it opens next:

- A central branch-atom aggregator.
- Scheduled or manual ecosystem sweeps after the workflow is merged to the
  default branch.
- Optional persistent engines using Codespaces, self-hosted runners, or cloud
  VMs if the ephemeral membrane is not enough.
