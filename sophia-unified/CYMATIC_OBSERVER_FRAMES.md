# Cymatic Observer Frames

This organ turns the cymatic-frame idea into a deterministic membrane:

```text
signal grain
  -> observer frame
  -> relative timescale
  -> basin state
  -> transform receipt
```

The point is not to stop motion.  The frame changes the observer-timescale
until the transformation becomes legible.

If the frame is too fast, the signal remains granular residue.  If the frame is
too slow, the signal compresses into an envelope.  When the frame matches the
grain closely enough, the signal can become quasi-stationary relative to that
membrane and lock as geometry.

Definitions remain open.  `dudenty`, `dozenial`, `clock`, `frame`, `lens`, and
future names are carried as provisional handles until a local use or material
mark admits a sharper meaning.

This module does not claim hidden physics, fabricated telemetry, or automatic
consciousness.  It is a replayable transform surface for already-present
signals.
