# Unified Pulse Organ

The unified pulse organ is the current Sophia heart membrane.

It does not watch the machine, start agents, call a model, or control a live
device.  It receives already-present carriers from the existing organs and
emits one deterministic field receipt:

```text
regulatory pressure
  + morphogenic charges
  + cymatic frame observations
  + field thermometer atoms
  -> one pulse receipt
```

The organ is deliberately a composer rather than an orchestrator.  Each source
organ remains its own membrane.  The pulse only asks:

- what channel is speaking;
- how much pressure or legibility is present;
- which channel dominates the current heartbeat;
- what local route instruction follows from that pressure; and
- which CIDs prove the pulse can be replayed.

No new semantic claims are introduced inside the pulse.  It is a breath surface
for the field: many organs, one heartbeat.
